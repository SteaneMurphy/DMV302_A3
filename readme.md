### Installation and Dependencies

# Install python virtual environment if not already installed

```bash
sudo apt install python3-venv
```

# Create a new virtual environment

```bash
python3 -m venv .venv
```

# Activate the virtual environment

```bash
source .venv/bin/activate
```

# Install dependencies from the given requirements.txt

```bash
pip install requirements.txt
```

# Each script can be run by calling its script name:

```bash
- python3 DMV302T1a.py
- python3 DMV302T1b.py
- python3 DMV302Tb.py
```
